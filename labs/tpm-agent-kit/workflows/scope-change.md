# Evaluate this scope change

## Inputs
Program profile, review date/timezone, current registers, relevant source notes or tracker exports. State unavailable or stale inputs before making conclusions.

## Method
Record requested change and business reason. Compare accept now, defer, reduce scope, and reject where meaningful. Trace effects on milestones, dependencies, capacity, quality, and cost using known inputs. Preserve current baseline until authority approves a replacement.

## Output
Change record; options and tradeoffs; evidence/unknowns; recommendation; decision authority and needed-by date; approved baseline delta if supplied.

## Finish
Check every substantive claim against its source. Mark recommendations as proposed. Save authorized local artifacts; draft external changes for review. Report what was completed and what remains unresolved.
