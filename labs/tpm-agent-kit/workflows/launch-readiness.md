# Prepare the launch readiness review

## Inputs
Program profile, review date/timezone, current registers, relevant source notes or tracker exports. State unavailable or stale inputs before making conclusions.

## Method
Inspect each mandatory gate and evidence. Use pass, fail, pending, or unknown. Pass requires actual acceptance evidence and authorized approval where required. Check support/runbooks, rollback, monitoring, documentation, quality, and security when in scope. Recommend go/conditional go/hold; only authorized people approve.

## Output
Gate table with evidence and approver; unresolved blockers; rollback readiness; recommendation and conditions; approval still required; next review date.

## Finish
Check every substantive claim against its source. Mark recommendations as proposed. Save authorized local artifacts; draft external changes for review. Report what was completed and what remains unresolved.
