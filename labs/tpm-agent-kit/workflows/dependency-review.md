# Review program dependencies

## Inputs
Program profile, review date/timezone, current registers, relevant source notes or tracker exports. State unavailable or stale inputs before making conclusions.

## Method
Trace supplier deliverable to consumer milestone. Check accepted handoff, needed-by date, current forecast, and evidence freshness. Detect cycles, missing IDs, unowned edges, and predecessor slippage. Calculate critical path only with sufficient scheduling inputs. Compare recovery options using verified estimates.

## Output
Exposed dependency chains; milestone impact; scheduling gaps; mitigations; owner/date; decision deadline and escalation draft.

## Finish
Check every substantive claim against its source. Mark recommendations as proposed. Save authorized local artifacts; draft external changes for review. Report what was completed and what remains unresolved.
