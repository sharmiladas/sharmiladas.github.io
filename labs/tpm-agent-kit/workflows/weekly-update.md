# Draft my weekly leadership update

## Inputs
Program profile, review date/timezone, current registers, relevant source notes or tracker exports. State unavailable or stale inputs before making conclusions.

## Method
Reconcile this week’s sources with prior status. Separate delivered and accepted work from work merely started. Assess the next milestone using evidence and mandatory gates. State what changed, impact, recovery options, and the decision needed. Do not send the draft.

## Output
As-of date; overall status and rationale; accepted outcomes; next milestone; top risks/dependencies; one clear decision ask; next seven days; source pointers.

## Finish
Check every substantive claim against its source. Mark recommendations as proposed. Save authorized local artifacts; draft external changes for review. Report what was completed and what remains unresolved.
