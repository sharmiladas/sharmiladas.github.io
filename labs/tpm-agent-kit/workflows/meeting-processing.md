# Process this meeting

## Inputs
Program profile, review date/timezone, current registers, relevant source notes or tracker exports. State unavailable or stale inputs before making conclusions.

## Method
Record meeting source ID, date, and attendees when supplied. Extract explicit decisions with authority; distinguish discussion from approval. Capture commitments and unconfirmed proposals separately. Reconcile stable IDs against existing registers; retain source excerpts or precise pointers. Identify affected milestones and handoffs.

## Output
Concise meeting note; decisions; actions with accepted or proposed owner/date; new risks/issues; register changes; unanswered questions.

## Finish
Check every substantive claim against its source. Mark recommendations as proposed. Save authorized local artifacts; draft external changes for review. Report what was completed and what remains unresolved.
