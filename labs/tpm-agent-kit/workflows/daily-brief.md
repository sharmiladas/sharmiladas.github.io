# Start my program day

## Inputs
Program profile, review date/timezone, current registers, relevant source notes or tracker exports. State unavailable or stale inputs before making conclusions.

## Method
Read milestones, active issues, dependencies, decisions, and actions. Rank today’s work by milestone impact and time sensitivity. Surface overdue decisions and missing owners. Use calendar only when actually connected.

## Output
Top three priorities with impact; decisions due; exposed handoffs; meetings to prepare; missing evidence; next action.

## Finish
Check every substantive claim against its source. Mark recommendations as proposed. Save authorized local artifacts; draft external changes for review. Report what was completed and what remains unresolved.
