# Build a program charter

## Inputs
Program profile, review date/timezone, current registers, relevant source notes or tracker exports. State unavailable or stale inputs before making conclusions.

## Method
Extract customer problem and target outcome. Establish boundaries, acceptance criteria, workstream owners, milestones, and dependency handoffs. Separate approved scope from proposals. Draft a rolling 30/60/90 plan with capacity assumptions and decision checkpoints.

## Output
Problem and recommendation; charter; workstream table; integrated milestone calendar; dependency register; open assumptions; decisions needed.

## Finish
Check every substantive claim against its source. Mark recommendations as proposed. Save authorized local artifacts; draft external changes for review. Report what was completed and what remains unresolved.
