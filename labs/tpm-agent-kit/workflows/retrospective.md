# Run a program retrospective

## Inputs
Program profile, review date/timezone, current registers, relevant source notes or tracker exports. State unavailable or stale inputs before making conclusions.

## Method
Compare committed outcomes to accepted outcomes. Use evidence to identify delays, rework, decision latency, handoff failures, and useful controls. Avoid blame and invented causal claims. Choose at most three operational improvements with owners, measures, and review dates.

## Output
Outcome comparison; contributing factors and evidence; retain/change/stop; three improvements; follow-up checkpoint.

## Finish
Check every substantive claim against its source. Mark recommendations as proposed. Save authorized local artifacts; draft external changes for review. Report what was completed and what remains unresolved.
