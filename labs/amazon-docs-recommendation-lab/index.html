What was measured

Actual offline development run: eight queries, including two requests with no relevant label. Relevance labels are proposed learning judgments. Other useful documents may be unlabeled; precision is especially sensitive to this incomplete labeling.

MethodPrecision@3Recall@3NDCG@3MRRNegative abstention

Ranking averages use six positive dev cases; negative abstention uses two cases. Fixed three-slot precision counts missing slots as nonrelevant. No production, conversion, or user-impact measurement is claimed.

Build it in four weeks

  1. Sources and objectives: inspect the source pages, stage public HTML for review, and define platform, task, audience, and lifecycle metadata.
  2. Ranking: compare query and related-document matching across lexical, vector, and metadata approaches. Inspect why each result was returned.
  3. Evaluation: independently label candidate relevance, calibrate reviewers, inspect regressions, and preserve the topic-grouped test set.
  4. Serving and feedback: run the local API, test the browser UI, and design a consent-based pilot with task-completion measures and review owners.

Architecture and scope

Vectors, tags, and recommendation algorithms

TF-IDF uses term counts and corpus frequencies, then cosine similarity between normalized sparse vectors. It is a real vector baseline, not a learned semantic embedding. Hybrid scoring combines 75% cosine, 20% query/tag overlap, and a 5% audience match when content or tag terms overlap. Related-document discovery excludes the current document. All modes enforce platform, active status, and public visibility.

Ingestion and content engineering

The included ingestion script stages main article text and checksums from a single approved public URL or local HTML export. Human review is required before indexing. This demo uses concise original summaries and reviewed tags; it does not automatically scrape a portal or generate LLM metadata.

Privacy, feedback, and maintenance

Useful/not-useful counters are stored only in this browser. They do not identify users or change ranking. Reset feedback removes those counters. No credentials, purchase history, personal profiling, or server query logging is used. Production authorization, monitoring, a learned model, and an MCP adapter remain future extensions.

Uncertainty and incorrect matches

A nonzero score only means shared features. It does not certify relevance or make a technical claim correct. Generic words can produce weak matches; no-result checks are intentionally limited. Verify source guidance and platform applicability before implementing it.
