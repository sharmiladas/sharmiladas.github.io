Baseframe DocGate

A small Python API and documentation sample for reviewing developer quickstarts. Send Markdown to a local endpoint, inspect structural findings, and revise the page. An optional client sends a document to the Claude Messages API for an editorial review.

This is a new, AI-assisted portfolio sample prepared for Sharmila Rammohan in November 2026. It contains synthetic documents, not employer material. Local HTTP behavior is tested; the Claude integration is tested with fixtures and has not been live-verified. Source code and documentation were developed with AI assistance.

  2. Improve a page in the tutorial.
  3. Look up the API contract.

Run the checks

Requires Python 3.11 or later. No third-party packages or API keys are needed.

python3 -m unittest discover -s tests -v

Scope

The service binds to 127.0.0.1, has no authentication, and stores no documents. Use it as a local demo. A zero-finding review is not a quality certification. This narrow line-based checker supports triple-backtick fences; it is not a full Markdown parser. It does not validate links, run submitted code, or verify claims.
