The problem

A program can appear busy while a required handoff remains unowned or a launch decision has no supporting evidence. Program leads spend time reconciling meeting notes, plans, and tracker updates before they can explain what needs attention.

What I built

A reusable agent operating kit that connects outcomes, workstreams, milestones, dependencies, risks, decisions, and acceptance evidence. It gives an AI assistant a structured workspace and eight repeatable workflows. Each operational record retains its source, owner, status, and verification date.

Run with a local workspace

Requires Python 3.10 or newer. No third-party Python packages are required. Clone the portfolio repository and enter the kit directory:

git clone https://github.com/sharmiladas/sharmiladas.github.io.git
cd sharmiladas.github.io/labs/tpm-agent-kit
python3 scripts/setup.py --workspace ./my-program

The utility creates a new workspace and refuses to overwrite an existing directory. Open it in an assistant with authorized file access, ask it to read AGENTS.md, fill in context/program-profile.md, and supply current program sources. Save updated records between sessions.

The worked example

A fictional knowledge-platform pilot has 12 workstreams. Unapproved permission mapping exposes three handoffs ahead of a readiness review. The agent should report an amber review status, identify the missing forecasts, and request a sponsor decision. It should recommend holding launch until mandatory gates have acceptance evidence.

The demo includes 32 passing evaluation cases out of 40. The 90% threshold is proposed, so the agent must not treat it as approved or present the result as a quality improvement. The remaining workstreams retain unknown status when no evidence is supplied.

Design choices and validation

Stable record IDs support reconciliation across reviews. Mandatory failed gates prevent a launch recommendation even when other streams look healthy. A critical path requires scheduling inputs; an exposed chain alone is insufficient.

Workspace creation, overwrite protection, package integrity, and internal Markdown links were checked. The kit also includes ten agent acceptance scenarios covering unsupported claims, duplicate records, stale evidence, approval boundaries, and imported instructions. Those scenarios are provided for evaluation; a live model or connected deployment has not been validated.

Current scope

Version 0.1 is a file-based prompt and workspace kit. An AI assistant performs the reasoning. Live tracker connections, MCP servers, background jobs, and a hosted application are future extensions. The example is fictional; no production adoption or time savings are claimed.
