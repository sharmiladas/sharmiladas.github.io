## Build, run, and customize

Static HTML, CSS, and JavaScript; no build tools or API credentials for the portfolio.

```bash
git clone https://github.com/sharmiladas/sharmiladas.github.io.git
cd sharmiladas.github.io
python3 -m http.server 8000
```

Open http://localhost:8000. To make your own version, fork this repository and clone your fork instead. Edit the section HTML files; shared sidebar and breadcrumbs use `portfolio-navigation.css`. `portfolio-navigation.js` preserves old homepage bookmarks. Update navigation consistently and set one active section. Preserve linked articles and downloads when moving content.

Use each product’s README for prerequisites, run commands, customization, tests, and source-access limits. A folder can be copied into a dedicated repository later without changing the product overview URL. Check the applicable license before redistribution.

## Publish

The public website is served by GitHub Pages from this repository. In your fork, configure Pages for your chosen branch and hosting method, replace personal and absolute links, and verify the section pages and downloads. Project repositories use `/repository-name/` in their Pages address; keep local links relative.
