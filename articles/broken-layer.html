Stop Rewriting the Prompt and Find the Broken Layer

A weak AI output is a diagnostic signal. Treat it like a systems problem.

The six-layer diagnosis

Start with knowledge: was the right information available and authoritative? Then retrieval: did the system find it? Context: was the useful evidence preserved? Generation: did the model follow the task? Evaluation: did the gates detect the miss? Governance: should a human or policy have intervened?

Prompts cannot repair missing truth

Prompt iteration is useful when instructions are genuinely unclear. It is wasteful when the system lacks the correct source, retrieves the wrong version, or has no explicit quality bar.

Make failure actionable

The goal is not merely to score an output. It is to route the failure back to the layer that can be improved. That is how an AI content system learns instead of accumulating patches.

AI content strategy is the design of the decision system around generation.
KNOWLEDGE → RETRIEVAL → CONTEXT → GENERATION → EVALUATION → GOVERNANCE → LEARNING
