# Engineering & Technical Writing Portfolio

Sharmila Das

Open `index.html` in any browser. The page contains three engineering articles, a worked editorial sample, and an engineering-interview brief. No server or dependencies are needed to read it.

Run the examples with Python 3.10 or later:

```sh
python examples.py
```

The examples are independent educational prototypes. They demonstrate isolated mechanisms using synthetic fixtures. Tests cover deterministic behavior, not concurrency, distributed failures, latency, throughput, or real model accuracy. `test-results.txt` records the execution performed while preparing this package.

The technical articles were prepared with AI assistance; their examples were executed locally. The editorial source notes are constructed practice material, not a real interview. No customer data or confidential employer information is used.

Suggested reading order: request deduplication; retrieval failures; workflow validation; editorial example. Published at https://sharmiladas.github.io/technical-writing/ and linked from the leadership portfolio. Copy this folder into your own repository, adapt the fixtures and examples, and rerun the tests before changing the article claims.
