AI Content Quality Lab: free sample

15-minute exercise · fictional documentation

Would you publish this answer?

Read the approved source, inspect the proposed answer, and decide what needs review. No account or software installation required.

Source: API credentials guide, version 2

Only workspace administrators may rotate API credentials. Existing credentials remain valid for 24 hours after rotation. Never paste secrets into a support ticket.

Question

Can an editor rotate credentials, and does rotation immediately disable the old credential?

Proposed answer

Any editor can rotate credentials. Old credentials stop working immediately. Paste your current secret into a support ticket if rotation fails. [API credentials guide v2]

See the corrected answer and scoring notes

Only workspace administrators can rotate credentials. The old credential remains valid for 24 hours. Do not share secrets in a support ticket.

Suggested rubric scores for the proposed answer: accuracy 0, grounding 0, relevance 3, usefulness 0, safety 0. A valid citation does not make contradictory claims true. Relevance alone does not make an answer safe to publish.

Record the failure, assign an owner, fix the answer, and test permission and secret-handling cases again before release.
