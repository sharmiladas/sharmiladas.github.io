## Build, run, and customize

Static HTML, CSS, and JavaScript; no build step or API keys. Run `python3 -m http.server 8000` from this folder. Edit each section HTML file, `baseframe.css`, and the shared navigation on all pages. Keep one active sidebar item and a breadcrumb matching the page. `baseframe-navigation.js` redirects older homepage bookmarks.

Fork the public portfolio repository, or copy this folder to a standalone repository. Replace branding, service descriptions, evidence, bio, and contact links with your own. Update canonical URLs and repository links. Check applicable licensing before redistribution. Configure GitHub Pages for the copy and verify all local links. Keep proposed learning products labeled as planned or early access.
