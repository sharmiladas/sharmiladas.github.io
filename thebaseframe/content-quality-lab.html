Free practical lab · Weeks 1–4

Learn to evaluate AI content with evidence.

Build a test set, calibrate human judgments, automate useful checks, and compare experiments. This downloadable Python lab gives you a complete starting workflow and a four-week guide.

Download the labView code and README

Included: 50 test cases, 10 sample documentation sources, five scoring dimensions, review templates, automated coverage checks, evaluator comparison, retrieval experiments, and a product decision memo.

Four weeks of hands-on work

1 Build the test dataset

Define expected behavior for answerable questions, missing information, stale sources, access controls, and conflicting evidence. Keep related cases in the same dataset split.

2 Calibrate human scoring

Score accuracy, grounding, relevance, usefulness, and safety. Compare independent reviewer judgments and document why they disagree.

3 Run automated checks

Check term and citation coverage, route critical cases to review, and compare imported LLM evaluator scores against human ratings.

4 Compare experiments

Run the included retrieval comparison. Then collect real model outputs for two prompts, hold other settings constant, and write a release recommendation.

What the results mean

Example answers and real evaluations

The demo answers are hand-authored fixtures on fictional documentation. Their scores are not evidence of LLM improvement. Import actual model responses and independently scored human reviews before making model-performance claims.

Coverage is a signal, not a factuality verdict

A term can appear in a false statement, and a citation can point to a document that does not support a claim. Use automated checks to find issues; use the rubric and source evidence to judge content.

LLM evaluator and release decisions

The package includes an evaluator prompt and import template. It does not call a model automatically. Critical cases always require review, and the harness does not certify production readiness.

Make it your own

Fork the repository or copy the lab folder, substitute sources you have permission to use, adapt the rubric to your users, and preserve a held-out test set. Keep model configuration, source versions, costs, and reviewer decisions in the experiment record.
